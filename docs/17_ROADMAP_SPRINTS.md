# Complex MVP Roadmap

## Phase 0 — Documentation
Freeze PRD, business rules, architecture, database, API contracts and UX.

## Phase 1 — Foundation
Monorepo, Expo apps, Next.js admin, Supabase environments, CI/CD, design system, auth skeleton.

## Phase 2 — Identity & Profiles
Auth, roles, profiles, onboarding, role routing, permissions.

## Phase 3 — Merchant & Catalog
Merchant onboarding, store, hours, categories, menus, variants, addons, availability.

## Phase 4 — Customer Commerce
Discovery, search, merchant detail, cart, address, checkout calculation.

## Phase 5 — Order Engine
Order creation, state machine, merchant acceptance/rejection, cancellation.

## Phase 6 — Payment
Cash/manual first, then provider abstraction and online payment integration.

## Phase 7 — Driver & Delivery
Driver onboarding, online state, assignment, pickup, delivery, proof.

## Phase 8 — Promotion & Reviews
Vouchers, discounts, reviews, ratings.

## Phase 9 — Finance
Merchant earnings, driver earnings, platform earnings, settlements, reconciliation.

## Phase 10 — Admin Operations
Orders, dispatch, incidents, users, merchants, drivers, reports, audit.

## Phase 11 — Hardening
RLS, security, performance, error handling, observability, E2E.

## Phase 12 — Production
Staging pilot → controlled launch → monitoring → iterative improvements.

## Definition of MVP Complete
All four mobile apps and admin web are functional enough for real operational use, with the full order-to-delivery lifecycle and financial/audit controls.
