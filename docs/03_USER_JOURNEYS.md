# User Journeys

## Customer
Onboard → set location → browse → merchant detail → add items → cart → address → voucher → payment → order tracking → delivery → review/reorder.

## Merchant
Apply → approval → configure store → configure catalog → receive order → accept/reject → prepare → mark ready → handoff → see earnings.

## Driver
Apply → approval → go online → receive delivery offer → accept → pickup → verify → navigate → deliver → proof → earnings.

## Operations
Login → dashboard → monitor orders → identify exception → intervene → resolve → audit.

## Finance
Review payments → reconcile → calculate earnings → approve settlement → export reports.
