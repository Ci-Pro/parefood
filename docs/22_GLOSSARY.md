# Glossary

Customer = pengguna yang membeli makanan.
Merchant = bisnis/restoran/warung yang menjual makanan.
Driver = pengemudi yang mengantar pesanan.
Order = transaksi pemesanan dari satu customer ke satu merchant.
Delivery = proses pengantaran order.
Service Area = wilayah layanan platform.
Delivery Zone = zona yang menentukan kelayakan/biaya delivery.
Settlement = proses pembayaran hasil usaha kepada merchant/driver.
RLS = Row Level Security PostgreSQL.
Edge Function = server-side function untuk operasi backend.
