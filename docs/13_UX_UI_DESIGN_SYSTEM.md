# UX/UI & Design System

## Product personality
Local, trustworthy, modern, warm, fast, easy for ordinary users.

## UX rules
- Indonesian language
- clear CTAs
- large touch targets
- low cognitive load
- meaningful empty/error/loading states
- offline-aware UX where practical
- never hide important price/fee information

## Shared design system
Tokens:
- typography
- spacing
- radius
- elevation
- semantic colors
- icon rules
- motion rules

Shared components:
Button, Input, Select, Modal, Sheet, Card, Badge, Avatar, Price, Status, Loading, EmptyState, ErrorState, Toast.

Feature-specific screens remain in each app.
