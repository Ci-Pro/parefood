# Production Release Checklist

## Product
- critical journeys tested
- merchant and driver onboarding verified
- cancellation/refund rules verified
- support flow ready

## Security
- RLS tested
- service keys protected
- webhook verification enabled
- audit logs active

## Finance
- totals reconciled
- payment records consistent
- settlement calculations verified
- refund workflow tested

## Operations
- admin dashboards working
- alerts working
- incident procedures documented

## Mobile/Web
- release builds verified
- environment variables correct
- crash monitoring active
- app versioning configured

## Rollout
- staging pilot
- limited merchant/driver launch
- monitor
- expand gradually
