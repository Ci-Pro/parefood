# PareFood — Complex MVP Product & System Blueprint

This package is the baseline source of truth for designing and implementing PareFood.

## Scope
- 4 separate Expo React Native apps
- 1 Next.js Admin Web
- 1 Supabase backend
- 1 PostgreSQL database
- 1 Git monorepo

## Recommended implementation order
Documentation → Foundation → Identity → Merchant/Catalog → Customer Commerce → Order → Payment → Driver/Delivery → Promotion/Review → Finance → Admin → Hardening → Production.

## Important
The project intentionally targets a complex operational MVP. It should be complete enough for a controlled real-world pilot while avoiding unnecessary national-scale features.
